多智能体协作与治理体系Multi-Agent Collaboration & Governance System

架构设计 · 独立运行Architecture · Solo operation

让 AI 承担执行层,人只做判定与验收。

AI handles execution; humans only judge and accept.

  • 设计多 Agent 的角色分工、任务分级与派发规范:分析、计划、执行、验收、收束各有边界,复杂任务先出方案再动手。
  • 建立权限隔离与 Guardrails:按目录、操作类型、网络与凭证分级设闸,高风险动作必须人工授权后放行。
  • 用 Hook 在工具调用前后拦截与记账,并以红蓝对抗方式主动打靶验闸,以独立账本对照 Agent 自述,避免“自报自验”。
  • 建立事后审计与验证流程:交付件逐条对触点核验,未验证项显式标注;沉淀 70 余个 Skill 与判例库,使跨 Agent 口径一致、可追溯。
  • Designed role split, task tiering and dispatch rules across agents: analysis, planning, execution, acceptance and wrap-up each have clear boundaries, and complex work starts with a plan.
  • Built permission isolation and guardrails tiered by directory, action type, network and credentials; high-risk actions require human approval.
  • Used hooks to intercept and log around tool calls, red-teamed the guardrails, and cross-checked agent self-reports against an independent ledger to prevent self-certification.
  • Set up a post-hoc audit and verification process: deliverables are checked item by item against evidence and unverified items are flagged; 70+ skills and a precedent library keep behavior consistent and traceable across agents.

私有化 AI 内容生产平台Private AI Content Production Platform

独立设计与实现Solo design & build

Mac 调度、GPU 工作站生产的双机全链路,任务投出即自动执行并回收。

A two-machine pipeline: a Mac dispatches, a GPU workstation produces; jobs run and return automatically.

  • 整合生图、改图、抠像、放大、视频生成、文本、读图七类任务,统一为 JSON 任务协议 + 文件队列,多 Agent 与人工均可投单。
  • 部署 4 路 ComfyUI 专用实例 + 本地 LLM 服务,按任务类型自动点火,并实现实例之间的显存互让与互斥;投单前先探测显存,忙则不派。
  • 管理 30 余个 LoRA 与多条风格线;为批量机械活(打标、分类、读图抄字、初译)选用本地模型,把云端额度留给判断类任务。
  • 明确治理线:本地模型只当“手”不当“脑”,不开放自主执行与写权限,“自主决定”与“能动手”不在同一处出现。
  • Unified image generation, editing, matting, upscaling, video generation, text and vision jobs behind one JSON job protocol and file queue, open to agents and humans alike.
  • Deployed four dedicated ComfyUI instances plus a local LLM service that start on demand by job type, with VRAM yielding and mutual exclusion; VRAM is probed before dispatch and jobs hold when the GPU is busy.
  • Managed 30+ LoRAs and several style lines; routed bulk mechanical work (tagging, classification, OCR-style reading, first-pass translation) to local models, saving cloud quota for judgment tasks.
  • Set a clear governance line: local models act as hands, not brains, with no autonomous execution or write access, so “deciding” and “acting” never sit in the same place.
